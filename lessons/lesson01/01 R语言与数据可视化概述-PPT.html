包的安装和使用

R 包类似于Python 里的模块（module /package），就是别人提前写好、打包在一起的一堆现成 R 函数，拿来直接调用，不用自己从零写代码。

install.packages("ragg")
# 查看包的帮助说明
?ggplot2

基本绘图

数据类型

数据类型

向量(Vector)

向量是一维数组，通常可由c函数创建 向量的数据类型可以是数值型、字符串或者逻辑型（TRUE或FALSE）

R语言中向量的索引从1开始

# 创建一个一维向量
a <- c(2,5,8,3,9)
# 提取a向量中第2位的元素
a[2] #访问a向量中第2位的元素
[1] 5
a[c(2,5)] #访问a向量中第2、5位的元素
[1] 5 9

向量的计算

# 计算向量a的长度(元素个数)
length(a)
[1] 5
# 计算向量a的平均值
mean(a)
[1] 5.4
# 计算向量a的总和
sum(a)
[1] 27

矩阵(Matrix)

二维数组，其中的每个元素都是相同的数据类型

Matrix语法

基本语法

matrix(
  data, #数据，一般为向量
  nrow, #几行
  ncol, #几列
  byrow = FALSE #是否按行填充,默认按列填充
)

常用参数

参数 含义
data 放入矩阵中的数据
nrow 行数
ncol 列数
byrow 是否按行填充 
# 用matrix函数创建矩阵
a<-1:6           # 生成1到6的数值向量
mat<-matrix(a,   # 创建向量a的矩阵
  nrow=2,ncol=3, # 矩阵行数为2，列数为3
  byrow=TRUE)    # 按行填充矩阵的元素
mat              # 显示矩阵mat
     [,1] [,2] [,3]
[1,]    1    2    3
[2,]    4    5    6
# 给矩阵添加行名和列名
rownames(mat)=c("甲","乙")   # 添加行名
colnames(mat)=c("A","B","C")   # 添加行名
# 用t函数对矩阵转置
t(mat)                    # 矩阵转置
  甲 乙
A  1  4
B  2  5
C  3  6

数组(Array)

与矩阵类似，但维数可以大于2

array(
  data,    # 数据，一般为向量
  dim,     # 维度向量 c(行数,列数,层数...)
  dimnames # 各维度名称，可选
)
# 创建数组
dim1<-c("男","女")    # 指定第1个维度为2个元素
dim2<-c("赞成","中立","反对")       # 指定第2个维度为3个元素
dim3<-c("东部","西部","南部","北部")    # 指定第3个维度为4个元素
data<-round(runif(24,50,100))      # 生成24个均匀分布的随机数，并取整
d<-array(
  data,    # 数据
  c(2,3,4), # 三个维度的元素长度
  dimnames=list(dim1,dim2,dim3) #三个维度的名称
  ) # 创建数组并赋值给对象d

数据框(Data Frame)

数据框是R语言中最常用的数据类型之一，类似于Excel表格或SQL数据库中的表格。数据框可以包含不同类型的数据（数值型、字符型、逻辑型等），每列可以有不同的数据类型。

语法

data.frame(
  col1,col2,col3,...
)
# 写入姓名和分数向量
names<-c("刘文涛","王宇翔","田思雨","徐丽娜","丁文斌") # 写入学生姓名向量
stat<-c(68,85,74,88,63)  # 写入各门课程分数向量
math<-c(85,91,74,100,82)
econ<-c(84,63,61,49,89)

# 将向量组织成数据框形式
table1_1<-data.frame(
  学生姓名=names,
  统计学=stat,
  数学=math,
  经济学=econ)
 # 将数据组织成数据框形式，并储存在对象table1_1中
table1_1   # 显示table1_1中的数据
  学生姓名 统计学 数学 经济学
1   刘文涛     68   85     84
2   王宇翔     85   91     63
3   田思雨     74   74     61
4   徐丽娜     88  100     49
5   丁文斌     63   82     89
