3.2 dplyr包的主要函数

函数 主要作用 常用写法 示例
select() 选择指定列 select(数据, 列名) select(df, name, score)
filter() 按条件筛选行 filter(数据, 条件) filter(df, score >= 80)
arrange() 按某一列排序 arrange(数据, 列名) arrange(df, score)
mutate() 新增或修改变量 mutate(数据, 新变量 = 表达式) mutate(df, total = math + english)
rename() 修改列名 rename(数据, 新列名 = 原列名) rename(df, 成绩 = score)
summarise() 对数据进行汇总统计 summarise(数据, 统计量 = 函数(变量)) summarise(df, avg = mean(score))
group_by() 对数据进行分组 group_by(数据, 分组变量) group_by(df, class) 
library(dplyr)

df %>%
  select(...) %>%          # 选择列
  filter(...) %>%          # 筛选行
  arrange(...) %>%         # 排序
  mutate(...) %>%          # 新增/修改变量
  rename(...) %>%          # 修改列名
  group_by(...) %>%        # 分组
  summarise(...)           # 汇总统计

4 长宽数据转换

4.1 table1_1数据框的长宽数据转换

数据框table1_1中每一门课程占据1列，这种数据形式称为宽数据，但在用R进行数据分析和绘图时，需要将“课程”和“分数”放在单独的列中，这种格式为长格式

实现将宽数据转换为长数据的方法有：

  1. reshape2包的melt函数

  2. tidyr包的pivot_longer函数

4.1.1 reshape2包的melt函数

安装并加载reshape2包

# 本机已装就秒过，没装自动补装对应的R包
if (!requireNamespace("reshape2", quietly = TRUE)) {
  install.packages("reshape2")
}

语法说明：

melt(数据框,
  id.vars="id列名",
  variable.name="转换后变量列列名",
  value.name="值列名")
参数 说明
id.vars 保持不变的列名
measure.vars 需要转换的列名
variable.name 转换后变量列列名
value.name 值列名 
table1_1_long <- melt(table1_1, 
                 id.vars = "姓名", 
                 variable.name = "课程", 
                 value.name = "分数")

4.2 长宽数据转换课堂练习题

某班调查了 5 名学生一天使用不同类型手机 App的时长，单位为分钟。原始数据如下:

app_usage <- data.frame(
  姓名 = c("张三", "李四", "王五", "赵六", "小陈"),
  微信 = c(85, 60, 95, 70, 80),
  短视频 = c(120, 90, 150, 65,110),
  学习软件 = c(45, 80, 30, 90, 60),
  游戏 = c(60, 30, 100, 20, 45)
)

app_usage
  姓名 微信 短视频 学习软件 游戏
1 张三   85    120       45   60
2 李四   60     90       80   30
3 王五   95    150       30  100
4 赵六   70     65       90   20
5 小陈   80    110       60   45

要求：将上述宽数据转换成长数据，将“微信、短视频、学习软件、游戏”合并为变量 App类型，对应的使用时长存放在变量 使用时长中。 、在长数据基础上，计算每种 App 的平均使用时长。
